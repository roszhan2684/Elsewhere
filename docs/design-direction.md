# Design direction

**Design board (all screens):** the source files are in [design/board/](../design/board/). The published link (claude.ai/artifact/UaGkQBdMJ6YiWRPN1fEkAM) stopped working on 2026-10-23, so republish the board from these files if you need it online.

**Mood:** contemplative, cinematic, precise. Night-ink ground, editorial serif, one branching line.

## Tokens

| Token | Value | Use |
|---|---|---|
| `ink` | `#0D0E12` | page ground |
| `raised` | `#1A1D24` | cards, panels |
| `line` | `#2A2E38` | dividers, borders |
| `paper` | `#ECE8DF` | primary text, primary buttons |
| `muted` | `#9A9AA3` | metadata (passes 4.5:1 on ink) |
| `path-a` | `#7EB6FF` | Path A — cool and lighter |
| `path-b` | `#E8914A` | Path B — warm and darker |
| `shock` | `#FF5D73` | shocks only |
| `newsprint` | `#F3EEE3` | front pages |

- Path colors also differ in lightness, and every branch carries an **A/B label**. Color is never the only signal.
- **Type:** Newsreader for display and the futures' voices, Geist for UI, Geist Mono for metadata. If you prefer Fontshare, swap in Sentient + Satoshi.
- **Evidence chips are told apart by shape:**
  - FACT: solid
  - ASSUMPTION: outlined
  - INFERENCE: dashed
- **Confidence:** use words (High / Medium / Low) before any percentages.
- **Motion:** under 500ms; ease-out for reveals, ease-in-out for scrubbing. Use Easing Editor to tune curves.

## Idea 1 — one branching line (Rive)

Build **one** Rive file, `fork.riv`, with a state machine called `Fork`.

| Input | Type | Effect |
|---|---|---|
| `split` | Number 0–1 | trunk only → branches drawn out (420ms when animated) |
| `progressA`, `progressB` | Number 0–1 | how much of each branch is "solid" (loading) |
| `shockA`, `shockB` | Trigger | pulse ring at the shock point, branch dims to 35% |
| `focus` | Number 0 / 1 / 2 | none / A highlighted / B highlighted (hover, swipe on iOS) |

**Where it's used**

| Place | What it shows |
|---|---|
| Landing hero | `split` scrubbed by scroll position |
| Loading screen | the server sends `agent_done` over SSE, and the client adds about 1/9 to `progressA`/`progressB` |
| Fork dashboard header | at rest, split = 1 |
| Shock | fire `shockA` at the same moment the diff arrives |
| iOS | same file via the `RiveRuntime` Swift package |
| Favicon / app icon | static export of the split frame |
| Video | the screen recording catches it |

Unicorn.studio is optional: add a very soft bloom behind the hero line only. Skip it if it costs more than 2 hours.

## Idea 2 — front pages from 2028

- Shock results render as two newsprint front pages, one per path, dated at the current timepoint.
- A changed headline crossfades in under 400ms. Numbers roll with **NumberFlow** (`@number-flow/react`).
- A branch the shock didn't touch gets an "Unchanged by this shock" stamp and one line saying why. That line comes from `ShockDiff.applies_to`.
- The headline and deck are generated by Spark from the diff (a short schema-bound call). The stats come straight from WorldState.

## Idea 3 — debate mode

- A third chat tab ("Debate") next to Future A and Future B.
- One user question goes to both persona runtimes. A answers first, then B gets A's message *as text only*, plus its own branch state. B can disagree, but it can't adopt A's events.
- Claims stream with character offsets, so chips appear inline as the text arrives (Motion Primitives text effect).
- **Branch guard:** before sending, code checks every cited event id against the branch letter. If a sentence references the other branch's events, Spark rewrites it, and the UI shows "Branch guard rewrote one sentence." Judges get to see the isolation working.

## Idea 4 — "What decides this?"

- A bar chart (tornado style) of how much each assumption can swing the A–B cash gap at month 24.
- Pure TypeScript math from WorldState finance ranges, with no model call. It updates instantly while dragging.
- Assumption sliders write a `user_edit` event. A "Recompute narrative" button then runs the real Spark recompute for the text.
- The most decisive assumption is named in the headline and linked from the shock verdict.
